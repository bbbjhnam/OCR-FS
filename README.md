# 재무제표 PDF 엑셀 변환기

로컬 브라우저에서 PDF 또는 엑셀을 선택하면 다음 항목의 당기/전기 금액을 정리하고 엑셀 파일로 저장합니다. 여러 파일을 선택하면 파일별로 별도 시트가 만들어집니다.

- 자산총계
- 부채총계
- 자본금
- 매출액
- 영업이익
- 당기순이익

## 사용 방법

1. OCRmyPDF를 설치하지 않은 간단 버전은 `start_local_page.bat`을 더블클릭합니다.
2. 고품질 로컬 OCR 버전은 `start_ocr_server.bat`을 더블클릭합니다. 새 버전 주소는 `http://127.0.0.1:8788/server`입니다.
3. PDF 또는 엑셀 파일을 화면에 끌어다 놓거나 클릭해서 선택합니다. 여러 파일 선택도 가능합니다.
4. 상단 파일 탭 또는 결과 목록에서 각 파일의 추출 결과를 확인합니다.
5. `엑셀 저장` 또는 `OCR·엑셀 생성` 버튼을 누릅니다.

## 고품질 OCR 버전

`start_ocr_server.bat`은 로컬 서버 방식입니다. 텍스트가 이미 들어 있는 PDF는 OCR을 생략하고 바로 추출하며, 이미지 스캔 PDF만 선택한 모드로 OCR합니다. 엑셀(`.xlsx`, `.xlsm`)은 OCR 없이 셀 값을 직접 읽습니다.

```text
ocrmypdf --force-ocr --deskew --rotate-pages --pdf-renderer sandwich --sidecar OCR텍스트.txt -l kor+eng
```

속도를 우선할 때 **빠른 모드**는 아래 설정으로 OCR을 정확히 한 번만 실행합니다.

- `kor+eng`, PSM 6, 300 DPI

숫자 정확도를 우선하도록 기본 선택된 **정밀 모드**는 아래 5가지 설정을 비교합니다.

- `kor+eng`, PSM 6, 300 DPI
- `kor+eng`, PSM 4, 400 DPI
- `kor+eng`, PSM 11, 400 DPI
- `kor`, PSM 6, 400 DPI
- 기본 호환 모드

각 OCR 결과에서 목표 항목 인식 수, 금액 수, 한글 인식량을 점수화해서 가장 좋은 결과를 최종 OCR PDF와 OCR 텍스트로 저장합니다.

여러 파일은 PC 과부하를 피하도록 최대 2~3개씩 병렬 처리합니다. 한 파일이 손상되어 실패하더라도 나머지 파일은 계속 처리되며, 실패한 파일은 결과 화면과 엑셀에서 오류 및 미발견 항목으로 표시됩니다. 같은 이름의 파일을 여러 개 올려도 산출물이 서로 덮어쓰이지 않습니다.

OCRmyPDF가 설치되어 있지 않으면 텍스트가 이미 들어 있는 PDF만 추출하고, 화면에 설치 안내를 표시합니다.

`unpaper`가 설치된 PC에서는 `--clean` 옵션도 자동으로 추가합니다. `unpaper`가 없으면 `--clean` 없이 실행해서 실패를 피합니다.

엑셀 추출은 OCR PDF 내부 텍스트가 아니라 OCRmyPDF가 만든 텍스트 파일(`--sidecar`)을 우선 사용합니다.

기존 브라우저 단독 버전은 아래 순서입니다.

1. 이 폴더에서 `start_local_page.bat`을 더블클릭합니다.
2. PDF 파일을 화면에 끌어다 놓거나 클릭해서 선택합니다. 여러 파일 선택도 가능합니다.
3. 상단 파일 탭을 눌러 각 PDF의 추출 결과를 확인하고 필요한 금액을 수정합니다.
4. `엑셀 저장` 버튼을 누릅니다. 선택한 PDF별로 별도 시트가 만들어진 `.xlsx` 파일이 저장됩니다.

`index.html`을 바로 열면 브라우저 보안 정책 때문에 PDF 읽기가 막힐 수 있습니다.

텍스트가 들어 있는 PDF는 자동 추출됩니다. 이미지 스캔본 PDF는 브라우저가 글자를 읽을 수 없으므로 표에 직접 입력한 뒤 엑셀로 저장할 수 있습니다.

## OCR PDF 저장

스캔본 PDF는 `OCR PDF 저장` 버튼으로 OCR 처리를 시도할 수 있습니다.

- OCR이 완료되면 원본 파일명 뒤에 `_OCR완료.pdf`가 붙은 PDF가 별도로 저장됩니다.
- OCR 결과 텍스트로 표를 다시 채운 뒤 엑셀 저장을 할 수 있습니다.
- 첫 OCR 실행 시 한국어 OCR 데이터가 필요할 수 있어 인터넷 연결이 필요할 수 있습니다.
- PDF 페이지가 많거나 이미지 해상도가 높으면 시간이 오래 걸릴 수 있습니다.
- OCR 전에는 페이지를 고해상도로 확대하고, 여백을 잘라낸 뒤 흑백 대비를 높여 작은 한글과 숫자를 더 잘 읽도록 처리합니다.

## 참고

PDF 안에서 한 줄에 당기/전기 금액이 4개 잡히는 경우에는 예시 이미지 기준의 3번 칸과 5번 칸 금액을 사용합니다. 금액이 2개만 잡히는 경우에는 첫 번째 금액을 당기, 마지막 금액을 전기로 사용합니다.
